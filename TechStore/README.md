# TechStore — projeto prático de HTML e CSS

Site estático de uma loja fictícia de tecnologia. Para abrir, carregue `index.html` no navegador.

## Páginas

- `index.html`: página inicial e destaques da loja.
- `produtos.html`: catálogo de produtos de exemplo.
- `cadastro.html`: formulário demonstrativo de contato e cadastro.
- `login.html`: formulário demonstrativo de entrada.
- `quem-somos.html`: apresentação institucional da loja.

## Estilos e imagens

- `style.css`: folha principal conectada a todas as páginas. Importa `estilo.css` e define o cabeçalho e a navegação responsiva.
- `estilo.css`: estilos gerais de cores, conteúdo, tabelas, formulários e rodapé.
- `IMG/`: logo e ilustrações SVG usadas nas páginas.

Os formulários são demonstrativos: sem um servidor configurado, os dados não são salvos nem enviados.
